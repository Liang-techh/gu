# 蛊真人 · 九转 MUD

当前根目录已经切换为 **选项驱动 MUD / RPG 状态机**。系统负责给出合法选项，玩家负责选择；选择会改变人物关系、空窍、蛊虫、装备、资源、副本、福地、修为与最终结局。

在线试玩：`https://liang-techh.github.io/gu/`

旧的沉浸式视觉小说 / 自由输入原型保留在 `legacy.html`。

> 专有名词以仓库 `reference/novel/` 为背景依据。新增装备、部分蛊虫、部分杀招、数值、副本和分支属于同人游戏设计，不冒充原著正文。

## 已实装核心

- 从南疆青茅山、古月山寨体系开始
- 1–9 转完整境界：凡人蛊师 → 六转蛊仙 → 九转尊者
- 空窍 / 元海 / 真元；六转后切换仙元与福地经营
- 凡蛊 / 仙蛊：炼化、喂养、生机、饥饿、本命蛊、羁绊
- 蛊虫融合：月光蛊 + 小光蛊等路线；本命蛊参与融合时保留身份
- 装备系统：衣袍、护腕、靴、信物、行囊
- 杀招系统：凡道杀招、仙道杀招、核心蛊要求、领悟要求
- 副本：花酒遗藏、狼潮围寨、白骨传承、古战场残境、地灵考验、尊者之路残境
- 福地：资源点、仙元池、阵法、稳定度、灾劫
- 五域行路与蛊仙交易会
- 成就系统
- 九转后多结局；持有春秋蝉可开启隐藏时间线结局
- JSON 存档格式与浏览器自动存档
- 键盘数字键 1–9 可直接选择当前选项

## 主要文件

```text
index.html              MUD 主入口
legacy.html             旧视觉小说 / 自由输入原型
mud/
  data.js                九转、蛊虫、装备、杀招、副本、事件、结局数据
  engine.js              MUD 唯一规则状态机
  portraits.js           本地原创同人风格人物立绘 SVG 生成器
  app.js                 浏览器 UI / 存档 / 选项输入
assets/
  mud.css                MUD 主样式
reference/novel/         原文资料
```

## 玩法结构

```text
系统生成当前事件 / 可用行动
          ↓
玩家从选项中选择
          ↓
MUD engine 结算
          ↓
时间、资源、关系、蛊虫、装备、修为改变
          ↓
触发新事件 / 副本 / 飞升 / 福地 / 结局
```

这版不再把“自由输入”作为主玩法。未来如果接 AI，AI 只用于扩展系统给出的候选事件和对白；真正的状态修改仍由 `mud/engine.js` 判定。

## 角色立绘

人物形象采用 **本地原创同人风格重绘**。可以参考网络上常见的角色同人视觉方向，但不会直接热链或复制授权情况不明的图片到公开 GitHub Pages。后续如果拿到明确授权的图片，可以直接替换对应立绘槽位。

## 测试

```bash
npm test
npm run check:canon
```

CI 同时检查：

- MUD 四个脚本语法
- 旧版核心脚本语法
- 旧状态机回归测试
- 新 MUD 回归测试
- 原文术语检查

MUD 测试覆盖开局分支、本命蛊、杀招、融合、装备、商店、副本、六转福地、1–9 转、普通结局、春秋蝉隐藏结局和存档往返。

## 下一阶段优先级

1. 把青茅山前 30 天扩成更密集的 storylet：方正、方源、漠北、家族、狼潮、商队互相影响。
2. 给副本增加真正的房间事件、机关、战斗和隐藏奖励，而不是只做风险层数。
3. 增加更多原作蛊虫与清晰的来源标记；同人新增内容单独标为游戏设计。
4. 加入更多仙道流派、道痕克制、灾劫类型和福地资源链。
5. 后续接 AI 时只生成候选剧情 JSON，不允许 AI 直接写玩家数值。
