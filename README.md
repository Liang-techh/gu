# 蛊道：逆命录

一个受东方蛊修、逆命与资源博弈题材启发的开放式中文文字游戏。

## 运行

直接打开 `index.html` 即可游玩，也可以启用 GitHub Pages 后在线访问。

## 玩法

- 修炼、探索、狩猎、炼蛊、交易、休息、闭关与社交
- 大量动态变量：境界、真元、寿元、健康、饥渴、疲劳、伤势、心性、悟性、胆识、野心、名望、恶名、因果、气运、戒心等
- 多条道痕与成长方向：力道、智道、血道、运道、时道、剑道、梦道、奴道、炼道
- 蛊虫成长、饥饿、忠诚、耐久和组合效果
- 阵营声望、人物关系、随机事件、隐藏目标和多结局
- 浏览器本地存档，不需要服务器

## 参考资料

`reference/novel/` 保存用户提供、并由用户声明已获得作者授权的序章及六卷文本，共 2,335 个章节文件，用于游戏设计研究和检索。

游戏本体会优先采用原创角色、原创剧情与抽象化机制；如需使用原文内容，应遵守授权范围并保留相应版权记录。

本次导入明确排除了本地浏览器配置、历史记录、登录数据、缓存数据库和其他运行时隐私文件。

## 在线部署

仓库设置中打开 GitHub Pages，选择 `main` 分支和根目录即可发布。

## 开发协作

修改文件前应读取最新版本，保留现有内容，并使用清晰的提交说明。新增游戏机制时，同步更新玩法说明。
