# 蛊真人 · 青茅山文字沙盒

原“蛊道：逆命录”的 0.2 版。以仓库 `reference/novel/` 原文核对人物、地点、蛊虫与修行用词，移除旧版“灰潮镇”“纳息蛊”“伪仙”等自设体系。玩家扮演一位古月族人，在原著人物所在的环境中作出自己的选择。

**专有名词有原文出处；新增情节、人物数值、行动成本及成长速度是同人游戏改编，不冒充小说原剧情。** 本版是可玩的青茅山沙盒，不是全书、五域或蛊仙系统已经完成的宣称。

## 开始游玩

下载完整仓库后打开 `index.html`。文件必须与 `src/`、`assets/` 保持相对位置。没有构建步骤、运行时依赖、服务器接口或 API 密钥。

也可以在仓库目录运行 `python -m http.server 8000`，然后用浏览器打开 `http://localhost:8000`。这是可选的静态文件服务，不是游戏后台。

仓库原有部署方式仍适用：GitHub Pages 选择 `main` 分支与根目录。此次代码提交不等于已替用户启用 Pages；没有验证在线部署状态。

初次进入选择资质和种子，再处理“开窍之后”。建议先在“蛊虫”页炼化月光蛊，然后选择留在学堂经营关系，或到竹林以酒引蛊。遇到剧情或战斗时，先回“行止”作出选择。

## 已实现的玩法

| 内容 | 当前规模 / 行为 |
| --- | --- |
| 地图 | 青茅山内 10 个相邻地点，部分入口需要线索和前置选择 |
| 剧情 | 23 个节点、68 个选项；条件解锁、互斥结果、延迟后果 |
| 人物 | 7 位原著人物，分别记录信任、畏惧、敌意、人情、资源、修行进度和近期记忆 |
| 变量 | 开局 134 个数值/剧情状态字段；得到酒虫后 141 个，不计日志条数来凑数 |
| 修行 | 甲乙丙丁资质、一至五转、初阶/中阶/高阶/巅峰、主动突破和失败后果 |
| 蛊虫 | 实装月光蛊与酒虫；炼化、抵抗、使用、食料、饥饿、生机和本命反噬 |
| 生存与战斗 | 饥渴、疲劳、伤势、中毒；逐回合攻击、月刃、防守、逃离 |
| 经济 | 有限存货、买卖价差、自动饮食/养蛊、借债、劳作偿债、商队订单 |
| 存档 | 自动存档、3 个人工槽、JSON 导入导出、随机状态与后续事件持久化 |

### 选择真的会改变后来

- 帮助古月方正会留下人情，后来的归途冲突可解锁求援；只向他收费则不会解锁。
- 归还钱袋能换来古月漠北在考核中的帮助；私吞钱袋会在 48 小时后引来追问，继续否认还能导致冲突。
- 跟踪酒虫才能进入深处。独占遗藏、与古月方源分享、交给家族，会得到不同资源、关系和后续事件；不会最后全都获得同一份奖励。
- 履行商队订单能改善信任、补货和价格；留下订金却不交货会遭遇商队追究。
- 借款会生成到期事件。拖延、偿还、劳作抵债与赖账分别改变后来的处境，读档不能消掉未了事项。

“往事”页显示已发生的变化和未了事项的起因；后续地点不匹配时，事件继续等待，不会静默丢失。

## 原文资料与授权记录

`reference/novel/` 保留用户提供的序章与六卷文本。仓库原记录为共 2,335 个章节文件，并记载用户声明已获得作者授权；此版本未重新核实授权范围，也未改动、删除或再次导入小说文本。

不搬运整章文本到网页。游戏内“原文”页提供术语对应章节的链接。`scripts/check-canon.cjs` 在完整仓库中检查术语是否确实出现在所指章节；它不证明改编事件、数字或全书设定都与原著一致。

此前导入所排除的浏览器配置、历史、登录信息、缓存数据库和其他运行时隐私文件，继续不纳入项目。

## 测试

需要 Node.js 18 或更高版本，无需 `npm install`：

```sh
npm test
npm run check:canon
```

`npm test` 包含 32 项自动测试：分支分歧、延迟兑现、随机可重现、存档恢复、原子失败、地点条件、炼化、喂养、死亡、战斗、经济漏洞和多种子模拟。

本次实现时 32 项规则测试全部通过；还用 Chromium 的离线 DOM 验证了开局、炼化、七个页签、移动端无横向溢出和输入转义。该环境阻止网页导航，因此浏览器测试使用明确的存储替身，**没有把真实浏览器重启持久化、HTTP 部署或 GitHub Pages 说成已经验证**。

可选 `python tests/browser_smoke.py` 用普通本地 HTTP 服务检查真实浏览器加载、刷新与存档，需要自行安装 Python Playwright 和 Chromium。`CHROMIUM` 环境变量可指定浏览器路径。本次环境中该完整浏览器测试未通过导航限制，不计作通过。

完整小说没有复制到测试容器，所以 `check:canon` 脚本在完整仓库中的自动执行尚待运行；实现时对已用术语的核对来自仓库章节读取。

## 代码结构

- `src/content.js`：原文索引、变量词典、地图、人物与声明式事件。
- `src/engine.js`：与界面分离的确定性规则、条件判断、延迟队列、存档校验。
- `src/app.js` / `assets/game.css`：中文响应式界面、存读档、原文链接。
- `tests/engine.test.cjs`：无依赖的规则回归测试。
- `docs/DESIGN.md`：分支模型、扩展方式和明确边界。
