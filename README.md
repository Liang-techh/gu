# 蛊真人 · 青茅山开放叙事沙盒

0.3 版把原来的纯文字网页升级为 **视觉小说表现层 + 开放世界状态引擎 + 条件分支/延迟后果 + 人物话题 + 因果图**。底层 `content.js` 与 `engine.js` 的规则和存档格式保持不变，因此 0.2 的新版本存档可继续使用。

> 专有名词以仓库 `reference/novel/` 原文核对；新增剧情、数值、UI、关系变化与时间表属于同人游戏设计，不冒充原著正文。

## 直接游玩

下载完整仓库，打开根目录 `index.html`。也可以在仓库目录运行：

```bash
python -m http.server 8000
```

然后访问 `http://localhost:8000`。游戏不需要 API 密钥、账号或服务器后台。

## 0.3 的核心升级

### 1. 不再只是文字列表

“行止”页会根据当前位置生成山寨、学堂、客栈、竹林、河滩、石缝等不同场景氛围。剧情事件进入视觉小说式舞台：场景层、人物剪影、角色名牌、正文对话框和条件选项同时出现。战斗也使用独立舞台表现。

当前视觉资产采用本地 CSS / 矢量式构图，不请求外部图片，因此仍可离线游玩。后续可以逐步把这些槽位替换为正式背景图、立绘和 CG，而不改世界引擎。

### 2. 剧情与表现分层

新增 `src/narrative.js`：只保存场景、人物视觉元数据、对话话题和剧情分组，不直接改玩家状态。

现有结构现在明确分为：

```text
视觉小说表现层        assets/visual-*.css + src/visual-ui.js
        ↓
剧情 / 话题组织层     src/narrative.js + src/content.js
        ↓
世界规则层            src/engine.js
        ↓
确定性存档层          RNG / queue / history / localStorage + JSON
```

这对应我们要借鉴的方向：Ren'Py 的表现思路、Ink 的分支组织、Yarn 的话题式人物交互、Arrow 的剧情图，但不复制这些项目的代码，也不把游戏改成它们的技术栈。

### 3. 人物不再只有“交谈”

人物页现在会显示“选择话题”。不同角色拥有不同话题，例如修炼、学堂、考核、山外、蛊食、商队等；部分话题需要线索、人情、信任或过去的选择才显示为可用。

话题层目前复用原有关系结算规则，所以它首先解决“对话组织与条件解锁”。下一阶段可以继续把不同话题升级为独立的结构化后果，而不需要重做 UI。

### 4. 因果图

顶部新增“因果图”。它从真实 `D.events` 和每个选项的 `effects.schedule` 自动生成剧情结构视图，并按照开局、学堂、债务、遗藏、家族、商队、世界等分组。

颜色区分：

- 绿色：当前存档已经发生
- 金色：正在处理
- 蓝色：已经进入未了事项队列
- 灰色：尚未触发

因此剧情规模继续扩大后，不需要只靠人工记忆维护分支。

## 仍然保留的 0.2 核心系统

- 青茅山 10 个相邻地点与线索入口
- 23 个剧情节点、68 个选择、延迟后果
- 7 位原著人物的信任 / 敌意 / 人情 / 资源 / 修行 / 记忆
- 甲乙丙丁资质，一至五转与四个小境界
- 月光蛊、酒虫：炼化、食料、生机、饥饿、本命蛊反噬
- 真元、元石、资源库存、借债、偿债、商队订单
- 回合制战斗、逃离、月刃、伤势与中毒
- 自动存档、3 个手动存档、JSON 导入导出

## 文件结构

```text

  content.js        原文术语、地点、人物、事件与选择数据
  engine.js         确定性规则、时间、战斗、经济、存档验证
  app.js            原有可靠的浏览器交互层
```

## 测试

需要 Node.js 18+：

```bash
npm test
npm run check:canon
```

`engine.test.cjs` 继续验证原有状态机；`narrative.test.cjs` 检查每个现有地点都具有场景元数据、每个人物都有话题、话题条件使用安全表达式，以及所有延迟剧情边都指向真实事件。

视觉层不直接写 `s.v`、NPC 关系或剧情标记；所有真正游戏操作仍交回旧 `app.js → engine.dispatch()`，因此升级表现层不会绕过存档校验与事务规则。

## 下一阶段

最值得继续做的是把人物“话题”从表现层升级为真正的结构化对话节点：每个话题可读取人物记忆、当前地点、债务、关系与世界事件，并产生不同的条件后果。同时逐步加入正式原创背景图 / 人物立绘 / 蛊虫卡面，让视觉槽位从程序化占位升级为完整美术资产。
