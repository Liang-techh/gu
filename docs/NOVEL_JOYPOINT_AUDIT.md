# 《蛊真人》核心爽点与 simulation-first RPG 审读报告

## 范围与结论

审读对象为 `reference/novel`：序章及第 1—6 卷，共 2,335 个章节文件、约 23.6 MB。结论不把一次性巧合直接当成数值规则，而是抽象成四类可观察状态：信息、资源、关系/势力、世界压力。

最值得模拟的六类爽点：

1. 绝境中的高代价逆转：失败不是读档按钮，而是用生命、蛊虫、修为或未来确定性换一次重启/翻盘。
2. 信息优势与信息隐藏：先知、线索、身份伪装和误导让弱者可以提前布局，也让优势随时可能被重新解释。
3. 以小博大的资源套利：元石、时间、地形、稀缺物和敌人的欲望可以互相兑换。
4. 传承/遗迹的规则谜题：资格、顺序、克制、线索可信度和竞争者推进本身就是玩法。
5. 借势而非硬拼：玩家通过代理人、谈判、挑拨、公开/隐藏、制造时机和公共危机改变战斗条件。
6. 局部行动引发势力级重排：交易、身份暴露、救援或不作为，会改变 NPC 记忆、势力关系、区域经济和战争方向。

核心循环：

```text
获得线索/资源 → 选择公开、隐藏或误导 → 试探规则并承担代价
      ↑                                              ↓
NPC 记忆、势力反应、区域变化 ← 反转、追捕、结盟、新机会窗口
```

## 可观察状态与自由行动

信息应拆为 `fact / source / confidence / knownBy / valueByFaction / expiresAt`。玩家可以验证、保留、出售、伪造或延迟公开；NPC 只读取自己的知识、怀疑度和最近经历。

元石同时承担修炼、炼蛊、情报、贿赂、医疗、拍卖、补给和抵押品功能。时间同时承担价格变化、NPC 目标、战争推进、传承窗口和伤势恢复成本。高价值行动至少同时承担立即资源、暴露度、伤势/精神压力、机会窗口、关系债务、未来追踪中的两类代价。

传承应保存线索链、线索可信度、资格、路线/轮次、竞争者进度、资源消耗、已发现事实、失败后果和开放窗口。导演只打开或改变窗口，探索通过通用 Action/Event 结算；失败留下伤势、噪声、竞争者进度、错误线索或区域变化。

势力状态至少需要 `influence / tension / attitude / relations / logistics / casualties / legitimacy`。同一危机应同时产生共同敌人、资源管制、功勋排行、内部派系争夺和事后问责。NPC 要根据补给、记忆和关系迁徙、抢夺、求援、投靠或提高核验成本。

战斗应和逃跑、地形、伪装、诱敌、外交、时间压力及第三方冲突共用同一事件管线。高阶敌人应允许玩家用规则、环境、代理人、交易和时机取得局部胜利，而不是只靠数值平衡。

## 当前实现优先级

### MVP

1. 开窍/学堂竞争：资质、公开形象、家族关注、方正关系和竞争者记忆。
2. 元石—采集—炼蛊—治疗的多用途经济。
3. 酒香—花酒遗藏：线索链、耐心/诱导、探索顺序和失败保留。
4. 演武：连胜、伤势、名声、观察、下注和对手情报。

### 第二阶段

1. 商队/拍卖：竞价意图、抬价、抵押、借贷、匿名和交易追踪。
2. 狼潮/三寨联盟：战功、补给、伤亡、救援时延和战后权力重排。
3. 白骨山/三王传承：开放窗口、竞争者推进、规则谜题和贪婪惩罚。
4. NPC 记忆传播：同场观察、传闻扩散、信息失真和势力网络。

### 远期

1. 北原身份伪装、跨域压制、常山阴型合法性和暴露追捕。
2. 王庭/真阳楼：资格、外援义务、奖励归属、战争后勤和闯层压力。
3. 福地经营、宗门制裁、影宗重建和梦境争夺。
4. 五域战争、两天重叠、疯魔窟、天庭/长生天/个人势力的动态结盟。

## 设计判断

《蛊真人》最可迁移的不是某一章发生的固定事件，而是：**掌握不对称信息，承担真实代价，把有限资源组合成杠杆，迫使多个有记忆的行动者重新选择**。成功应让下一次局势更复杂；失败至少留下伤势、债务、怀疑、价格、关系、资源、区域危险或新线索。

> 校勘：梦境争夺实际对应第4卷第263章，而不是第262章。
