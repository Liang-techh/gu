# 《蛊真人》小说爽点系统审计（Agent 版）

> 目的：把 `reference/novel` 中可重复的高爽点拆成 simulation-first RPG 的状态、事件、记忆、势力反应和 AI 导演钩子。本文不是剧情梗概，也不把小说中的一次性巧合直接当作数值规则。
>
> 审计范围：序章及第 1—6 卷，共 2,335 个文本文件（约 23.6 MB）。对照当前 `src/`、`docs/SIMULATION_ARCHITECTURE.md`、`docs/NOVEL_JOYPOINT_AUDIT.md` 与 `docs/NOVEL_JOYPOINTS_DESIGN.md`。原文证据以已有审计列出的章节为抽样锚点；设计结论是系统抽象，不是对小说战力或概率的断言。

## 结论先行

《蛊真人》的可迁移爽感不是“每次升级更高数值”，而是玩家用不完整但有价值的信息，把有限资源、身份、规则和他人的欲望组合成杠杆；行动成功后，世界状态被重新排列，失败也留下伤势、债务、怀疑、价格、关系或新线索。

最适合成为核心循环的是：

```text
侦察/获得线索 → 选择公开、隐藏、伪造或延迟
       → 用资源、身份、规则或代理人试探
       → 承担暴露/伤势/债务/机会成本
       → 获得局部收益或反转
       → NPC 记忆、势力关系、区域资源和导演压力重排
       ↖                 世界继续推进，新的窗口出现
```

四条设计底线：

1. 失败不能等同于无成本读档；至少保留一项长期后果。
2. 公开成功、秘密成功、部分成功和带污染的成功必须分开。
3. 同一资源至少有两种用途；时间、情报、合法性和注意力也是资源。
4. 导演只打开窗口、制造压力和提出候选事件；具体后果必须经过通用 Action/Event/History/Memory/Faction 管线。

## 一、前 20 个爽点排序

排序标准是“玩家能否反复主动制造”与“能否同时驱动多个系统”。S 为最适合核心循环，A 为核心循环的强化层，B 为中后期高价值系统，C 为稀有事件或终局导演层。

|---:|---|---|---|

## 二、逐项系统映射

下表中的“组件”指实体或世界状态组件；“事件”指应进入领域事件流的事件类型；“记忆/势力/导演”分别说明长期观察者如何获得后果。

### 1. 信息差、先知与提前布局

- **世界状态**：`intel.leads`、`facts`、`source`、`confidence`、`knownBy`、`valueByFaction`、`expiresAt`；市场库存、传承窗口和事件倒计时。
- **实体组件**：`knowledge`、`brain`、`identity`、`inventory`、行动者的目标与风险偏好。
- **事件**：`intel.observed`、`intel.verified`、`intel.sold`、`intel.falsified`、`window.opened`、`market.price_changed`。
- **NPC 记忆**：记录“谁首先知道、信息来源、可信度、是否被验证、谁因错误信息受损”；不同 NPC 不能共享全局真相。
- **势力反应**：抢购、封锁、增派侦察、抬价、提前结盟或追查泄密者；情报价值随公开程度衰减。
- **AI 导演钩子**：在多个势力只掌握部分事实时打开短窗口；生成相互冲突的线索来源，不直接告诉玩家真相。
- **判断**：最强的通用爽点，必须成为所有传承、市场、身份和战争系统的底层能力。

### 2. 绝境中的高代价逆转

- **世界状态**：`deathPressure`、伤势、蛊虫耐久、修为、未来确定性、重启次数或“回响”资源。
- **实体组件**：`body`、`equipment`、`effects`、`cultivation`、`memory`、`provenance`。
- **事件**：`crisis.entered`、`sacrifice.accepted`、`reversal.triggered`、`scar.persisted`、`timeline.echoed`。
- **NPC 记忆**：幸存者记住玩家濒死、失踪、牺牲或突然出现；重启后的玩家可拥有事实回响，但 NPC 不应自动忘记上一轮。
- **势力反应**：把玩家视为危险异常、可利用的幸存者或不可信棋子；围杀者可能调整下一次封锁路线。
- **AI 导演钩子**：仅在失败不可由普通行动挽回且玩家支付明确代价时提供逆转选项；逆转改变未来变量，不复制存档。
- **判断**：是小说开篇最鲜明的结构，但应限制频率，作为高压核心出口而非常规治疗。

### 3. 身份伪装与示弱

- **世界状态**：`identityMasks`、`publicProfile`、`suspicionByObserver`、`revealedFacts`、地域合法性和能力压制。
- **实体组件**：`identity`、`knowledge`、`social`、`brain`、`publicReputation`。
- **事件**：`identity.adopted`、`identity.performed`、`suspicion.raised`、`identity.tested`、`identity.exposed`、`identity.reframed`。
- **NPC 记忆**：分别保存“看到的行为”“听到的传闻”“自己的怀疑”“已确认的事实”；NPC 可被玩家长期低估或错误引导。
- **势力反应**：低估时减少监视或给出廉价机会；怀疑升高时增加核验成本；暴露后可能追捕、招揽、要价或取消资格。
- **AI 导演钩子**：把揭牌窗口绑定到高价值行动、观察者能力和证据密度；允许玩家主动摊牌换取威慑或合法性。
- **判断**：应与公开名声、拍卖匿名、跨域旅行和演武共用一套机制。

### 4. 贫穷中的资源套利

- **世界状态**：元石、材料、食物、时间、医疗容量、区域资源、供需、债务和抵押品。
- **实体组件**：`inventory`、`needs`、`equipment`、`cultivation`、`knowledge`、`contracts`。
- **事件**：`resource.gathered`、`resource.exchanged`、`credit.opened`、`debt.incurred`、`shortage.created`、`price.shifted`。
- **NPC 记忆**：记住谁囤货、借款、救济、违约或在短缺时抬价；债务关系与信任不等价。
- **势力反应**：配给、制裁、保护商路、争夺采集点、向玩家提供条件性贷款。
- **AI 导演钩子**：当一种资源有两个以上高价值用途时制造冲突窗口；让玩家看见“买情报”和“买治疗”的真实机会成本。
- **判断**：核心经济。元石不能只做升级货币，至少同时承担修炼、炼蛊、情报、贿赂、治疗和补给用途。

### 5. 传承规则谜题

- **世界状态**：`inheritance.round`、资格、线索链、关卡顺序、贪婪标记、竞争者进度、已取奖励和失败后果。
- **实体组件**：`knowledge`、`ability`、`inventory`、`body`、`contracts`、竞争者 `brain`。
- **事件**：`inheritance.discovered`、`clue.decoded`、`trial.entered`、`rule.broken`、`reward.claimed`、`competitor.advanced`。
- **NPC 记忆**：记住玩家是否守规矩、是否抢夺、是否出售线索，以及哪个竞争者先到哪一轮。
- **势力反应**：代理人争夺、封锁入口、购买资格、交换路线、追责传承破坏者。
- **AI 导演钩子**：周期性开放窗口，改变入口、竞争者和线索质量；导演提供规则压力，不直接给奖励。
- **判断**：比线性“进入遗迹—打 Boss—掉宝”更适合 Qud 式模拟，是 P0/P1 重点。

### 6. 拍卖、交易与抬价

- **世界状态**：库存、估值、竞价者资本、`auctionHeat`、意图暴露、市场债务、交易追踪压力。
- **实体组件**：`inventory`、`knowledge`、`identity`、`relationships`、`contracts`。
- **事件**：`auction.opened`、`bid.placed`、`bid.probed`、`lot.won`、`intel.sold`、`transaction.traced`。
- **NPC 记忆**：保存出价模式、对某物的异常兴趣、卖家见证者、付款来源和玩家是否故意抬价。
- **势力反应**：同行抬价、联合封锁、雇佣追踪者、竞价联盟破裂或向玩家发出保护条件。
- **AI 导演钩子**：在稀缺物、公开观察者和多方预算同时满足时生成拍卖；不保证目标物一定出现。
- **判断**：可重复且系统价值极高，适合把现有 `auctionLot` 扩成通用市场动作。

### 7. 借敌人的欲望反制敌人

- **世界状态**：各 NPC 的欲望、恐惧、债务、声望目标、救援需求、贪婪和底线。
- **实体组件**：`brain.goals`、`relationships`、`memory`、`contracts`、`knowledge`。
- **事件**：`leverage.discovered`、`offer.made`、`favor.exchanged`、`desire.exploited`、`deal.broken`。
- **NPC 记忆**：记录玩家掌握了什么筹码、是否守约、是否用秘密要挟、对方因玩家而失去什么。
- **势力反应**：短期让步、内部派系争论、派代理人谈判、事后报复或提高未来交易门槛。
- **AI 导演钩子**：给同一事件安排互相冲突的 NPC 目标，让谈判、威胁、援助和等待都成为有效解。
- **判断**：是“资源差转化为政治差”的关键，应与合同、对话和派系 AI 联动。

### 8. 以弱胜强的非战斗解

- **世界状态**：地形、危险效果、逃生路线、规则免疫、时间窗口、第三方位置和战力不对称。
- **实体组件**：`body`、`effects`、`ability`、`knowledge`、`equipment`、`brain`。
- **事件**：`terrain.exploited`、`rule.invoked`、`escape.attempted`、`ambush.avoided`、`combat.deescalated`。
- **NPC 记忆**：记住玩家使用过的路线、招式、环境和谈判借口；重复使用会增加对手适应度。
- **势力反应**：调整巡逻、封锁环境、悬赏玩家或招募玩家作为特殊行动者。
- **AI 导演钩子**：为高战力敌人保留多个可观察弱点，但不强制玩家发现；失败应留下受伤、噪声或新情报。
- **判断**：Qud 式自由行动的必要条件，不能让数值战斗成为唯一解。

### 9. 让第三方互斗

- **世界状态**：势力敌对度、误导事实、可见证据、战斗计时、代理人位置和玩家暴露度。
- **实体组件**：`knowledge`、`identity`、`brain`、`relationships`、`combat`。
- **事件**：`rumor.seeded`、`faction.conflict_started`、`agent.misdirected`、`third_party.engaged`、`evidence.exposed`。
- **NPC 记忆**：旁观者各自保存不同版本；参与者记住谁引发冲突、谁袖手旁观、谁救援。
- **势力反应**：公开归因、报复、谈判、暂时停战或争夺玩家作为证人。
- **AI 导演钩子**：当两个势力已有张力且存在可验证/不可验证证据时生成冲突机会；冲突必须能在玩家不介入时自行结算。
- **判断**：核心强化层，直接把“战斗时间换炼蛊/逃生时间”系统化。

### 10. 炼蛊、组合与风险投资

- **世界状态**：材料配方、成功率区间、炼制时间、失败污染、蛊虫耐久、公共资源消耗和结果品质。
- **实体组件**：`inventory`、`equipment`、`ability`、`cultivation`、`effects`。
- **事件**：`refinement.started`、`material.consumed`、`refinement.failed`、`refinement.completed`、`contamination.spread`。
- **NPC 记忆**：记住玩家的专长、失败记录、配方来源、是否偷取材料或在危机中炼制。
- **势力反应**：招揽炼道能力、垄断材料、保护工匠、调查爆炸或把失败归咎于玩家。
- **AI 导演钩子**：在市场短缺、战斗压力或传承窗口中提供互相冲突的炼制时机；不把成功固定为剧情奖励。
- **判断**：适合做高频资源转换器，并与时间、市场和基地经营耦合。

### 11. 演武连胜与公开名声

- **世界状态**：`arena.matches/wins/losses/streak/reputation`、下注池、伤势、对手资料和观众热度。
- **实体组件**：`body`、`ability`、`equipment`、`publicProfile`、`memory`。
- **事件**：`match.offered`、`match.observed`、`match.resolved`、`streak.changed`、`bet.settled`、`style.learned`。
- **NPC 记忆**：记录连胜、败因、战斗风格、是否藏底牌、是否接受弱对手挑战。
- **势力反应**：提高邀请等级、下注、招揽、安排克制型对手或把玩家视为公开威胁。
- **AI 导演钩子**：根据热度和玩家名声改变对手池、下注和观察者；允许玩家选择保连胜、试验新招或故意输掉。
- **判断**：高重复性早期循环，现有 `arena` 已是良好骨架。

### 12. 公共危机中的战功与分配

- **世界状态**：前线、补给、战功、伤亡、救援时延、人口、区域危险、功勋榜和战后分配。
- **实体组件**：`body`、`brain`、`contracts`、`relationships`、`inventory`。
- **事件**：`crisis.declared`、`patrol.completed`、`rescue.delayed`、`casualty.recorded`、`merit.awarded`、`ration.changed`。
- **NPC 记忆**：记住谁守线、逃跑、抢功、救人、囤货或牺牲；战功与信任应可分离。
- **势力反应**：战功榜、晋升、内部问责、资源配给、临时联盟和战后派系争权。
- **AI 导演钩子**：持续推进狼潮/战争，不因玩家离开而暂停；把危机同时变成合作窗口和政治窗口。
- **判断**：P1 核心强化，适合验证世界离线推进和 NPC 自主行动。

### 13. 势力结盟、背叛和代理人博弈

- **世界状态**：`influence`、`tension`、`attitude`、`relations`、`logistics`、`legitimacy`、代理人目标。
- **实体组件**：`brain`、`relationships`、`contracts`、`knowledge`、`identity`。
- **事件**：`alliance.proposed`、`agent.deployed`、`support.exchanged`、`betrayal.detected`、`faction.realigned`。
- **NPC 记忆**：保存个人承诺与势力公开立场的差异；代理人失败不应自动等于派系全知。
- **势力反应**：暂时合作、要价、分裂、吞并、制裁或改变战争目标。
- **AI 导演钩子**：当共同威胁超过内部矛盾时生成联盟；当收益重新分配时生成背叛候选。
- **判断**：中期把个人行动提升到政治层，是多方世界而非单线主线的关键。

### 14. NPC 记忆与传闻扩散

- **世界状态**：`events.recent`、`History`、传闻可信度、传播边界、衰减时间、信息网络。
- **实体组件**：`memory.facts`、`memory.episodes`、`knowledge`、`relationships`、`brain`。
- **事件**：`memory.created`、`rumor.spread`、`rumor.decayed`、`fact.confirmed`、`witness.disagreed`。
- **NPC 记忆**：按观察者、时间、情绪、来源和置信度保存，不把传闻升级为事实；同一事件允许多个版本。
- **势力反应**：根据传播范围调整监视、价格、招募和追捕，而不是读取完整事件账本。
- **AI 导演钩子**：在玩家制造有见证者的事件后安排传播/失真；没有见证者的秘密成功不应凭空全图广播。
- **判断**：是所有爽点的长期回报层，优先级不低于新内容。

### 15. 匿名并非无痕

- **世界状态**：交易见证者、付款来源、物品 provenance、能力指纹、追踪压力、线索链。
- **实体组件**：`identity`、`knowledge`、`inventory`、`provenance`、`relationships`。
- **事件**：`trace.created`、`trace.linked`、`alias.used`、`investigation.opened`、`identity.confirmed`。
- **NPC 记忆**：卖家、护卫、同行、受益人各自记住部分交易；调查者通过多条弱证据逐步提升置信度。
- **势力反应**：封锁交易、雇佣侦查、提高核验、保护知情者或用追踪结果向玩家议价。
- **AI 导演钩子**：根据证据密度和调查资源生成调查，不按固定章节强制暴露；玩家可销毁、伪造或转移证据。
- **判断**：身份系统的反转发动机，适合连接拍卖、救援、炼蛊和跨域旅行。

### 16. 基地/福地经营

- **世界状态**：生产、人口、资源节点、防御、贸易、债务、制裁、迁徙和基地安全。
- **实体组件**：`inventory`、`contracts`、`brain`、`factionMembership`、`effects`。
- **事件**：`base.upgraded`、`resource.produced`、`trade.embargoed`、`invasion.scouted`、`resident.migrated`、`base.lost`。
- **NPC 记忆**：居民记住供给、保护、压榨和灾难中的决策；盟友记住基地是否兑现承诺。
- **势力反应**：提供保护换税、封锁商路、争夺资源、派卧底或提出合并。
- **AI 导演钩子**：当基地价值与外部压力同时上升时触发经营决策；基地不应成为永远安全的菜单界面。
- **判断**：P2 中期核心，能把“资源多了就被追杀”转成可玩的资产风险。

### 17. 跨地域身份与合法性

- **世界状态**：地域压制、语言/文化门槛、通行证、合法性、当地声誉、旅行风险和归属争议。
- **实体组件**：`identity`、`relationships`、`knowledge`、`equipment`、`publicProfile`。
- **事件**：`border.crossed`、`legitimacy.tested`、`local.favor`、`outsider.exposed`、`passport.granted`。
- **NPC 记忆**：记录玩家来自哪里、是否救援本地人、是否遵守习俗、是否冒充名门或敌对势力。
- **势力反应**：盘查、收编、保护、驱逐、抬高价格或要求完成地方义务。
- **AI 导演钩子**：在新区域同时提供外来者劣势与快速立足机会；成功救援、稀缺货物和代理人可改变合法性。
- **判断**：常山阴型中期系统，不能只用换地图解决。

### 18. 梦境、认知与高层资源争夺

- **世界状态**：梦境深度、认知进度、精神压力、进入权、所有权、探索权、现实映射和竞争者进度。
- **实体组件**：`knowledge`、`effects`、`ability`、`memory`、`identity`。
- **事件**：`dream.entered`、`dream.rule.discovered`、`dream.solved`、`dream.backlash`、`cognitive.fact.revealed`。
- **NPC 记忆**：记住玩家是否疯癫、获得何种知识、是否泄露梦境规则；梦中事实与现实确认要分开。
- **势力反应**：争夺进入权、雇佣解梦者、封锁现场、交易认知成果或把梦境污染视为公共危机。
- **AI 导演钩子**：在高层事件或梦境潮汐时打开有限入口；把解谜能力、代理人和风险预算作为不同路线。
- **判断**：重复性低但系统价值极高，适合作为中后期稀有高价值内容，不能作为 MVP 依赖。

### 19. 不行动造成的局势重排

- **世界状态**：时间、市场价格、NPC 目标进度、战线、资源再生、传承轮次、危机热度。
- **实体组件**：所有带 `brain` 的 NPC、`zones`、`factions`、`contracts`、`market`。
- **事件**：`time.advanced`、`goal.progressed`、`window.expired`、`faction.moved`、`price.rebalanced`、`zone.settled`。
- **NPC 记忆**：记住玩家未回应求援、错过竞价、放弃路线或没有保护某人；沉默本身产生关系变化。
- **势力反应**：其他势力占据资源、完成传承、迁移人口、改变联盟或把玩家判定为不可靠。
- **AI 导演钩子**：每次等待、旅行、休息和离区都结算离线世界；导演只能提出窗口，不能暂停世界等玩家点选。
- **判断**：核心导演原则，决定游戏是否真正 simulation-first。

### 20. 世界级遗产与终局重启

- **世界状态**：五域/两天热度、世界规则、终局压力、遗产归属、跨势力联盟、灾变阶段。
- **实体组件**：`memory`、`knowledge`、`identity`、`factionMembership`、`ability`、世界级状态组件。
- **事件**：`world.threshold.crossed`、`legacy.awakened`、`cosmic.realignment`、`realm.overlapped`、`endgame.phase_changed`。
- **NPC 记忆**：不同势力对世界真相保有不同叙事；少数高层 NPC 记住玩家在早期窗口做出的选择。
- **势力反应**：天庭/长生天/超级势力重新结盟、迁徙、封锁和争夺世界结构资源。
- **AI 导演钩子**：依据长期热度和玩家/势力累计后果切换阶段；不生成唯一“正确结局”，允许玩家留在局部经营或间接影响终局。
- **判断**：低频稀有事件/终局层，不应阻塞早期可玩性；它的价值在于让前面所有小行动最终有重量。

## 三、核心循环、强化循环与稀有事件边界

### 必须成为核心循环的内容

1. 信息获取、验证、出售、伪造和过期。
2. 元石/材料/时间/医疗/情报的多用途经济。
3. 身份伪装、公开形象、怀疑度和分层暴露。
4. 传承/遗迹的线索—规则—竞争者—失败后果循环。
5. 以弱胜强的环境、规则、谈判、逃跑和代理人解。
6. NPC 记忆、传闻传播、关系债务与势力反应。
7. 不行动时的离线推进，以及成功/失败留下的持久状态。

### 适合做核心循环的强化层

- 演武、下注、连胜和公开声誉。
- 拍卖、抬价、抵押、借贷和交易追踪。
- 狼潮/战争中的巡逻、救援、补给、战功和战后问责。
- 炼蛊与资源经营，尤其是时间窗口和失败污染。
- 代理人结盟、挑拨、临时停战和势力重排。

### 只做稀有事件或中后期内容的部分

- 梦境、疯魔窟、两天重叠等认知/世界规则事件。
- 五域战争、三尊级重排、天道与世界结构改变。
- 极低频的高代价重启；频繁使用会破坏资源风险和失败记忆。
- 需要大量专门 UI/内容的高层传承；先以通用 `inheritance` 契约验证机制。

“稀有”不等于线性。稀有事件仍应读取现有状态，产生多个可解释候选，并允许玩家错过、延迟或以代理人参与。

## 四、当前 gu-rpg 已覆盖与缺失

### 已覆盖或已有可复用骨架

- **持续世界与离线推进**：`zones`、区域驻留/缓存、NPC 目标、经济与冲突结算，已能支持玩家离开后世界继续变化。
- **组件化实体**：`body`、`equipment`、`effect`、`condition`、`ability`、`brain`、`knowledge`、`identity` 等组件边界已形成。
- **事件与历史账本**：领域事件、最近事件、`History`、provenance 和日志已能承载长期后果。
- **关系、记忆、传闻**：关系中的 trust/fear/debt/affinity、NPC 记忆和局部传闻传播已有基础；应继续提高来源与可信度区分。
- **势力与世界级状态**：`factions`、`frontier`、`worldWar`、`eternalWar`、`central` 等状态已覆盖从区域到世界级的容器。
- **合同、对话、目标与导演**：内容驱动合同、条件对话、NPC goal、导演规则和事件规则可作为通用入口。
- **区域 affordance**：观察、采集、遗藏搜索和侦查已被抽成可组合交互，能为玩家与 NPC 共用同一套 Interaction Registry。
- **演武/传承/塔楼/拍卖的状态容器**：已有 `arena`、`inheritance`、`tower`、拍卖相关状态，适合补机制而不是重写架构。
- **基础验证**：已有测试、内容 schema 检查、小说术语/来源检查和 365 日长跑审计；这些能证明运行稳定性，不能单独证明爽点覆盖或平衡。

### 关键缺失或不足

1. **信息模型还不够细**：需要统一的 `fact/source/confidence/knownBy/valueByFaction/expiresAt` 契约，避免全局 facts 代替观察者视角。
2. **身份系统未形成完整循环**：需要伪装强度、公开形象、按观察者怀疑度、证据链和暴露后的招揽/追捕分支。
3. **经济仍需多用途化**：元石、时间、材料、医疗和情报需要显式机会成本、抵押/借贷、短缺和区域价格反馈。
4. **传承规则尚未通用化**：已有状态容器，但线索质量、资格、轮次、贪婪惩罚、竞争者推进和失败保留应由同一契约驱动。
5. **拍卖/交易追踪不完整**：需要竞价意图、付款来源、见证者、provenance、匿名强度和追踪压力。
6. **战斗与非战斗解的共用结算不足**：逃跑、地形、谈判、诱敌、环境效果、第三方冲突和战斗应进入同一事件管线。
7. **NPC 记忆传播需要可见边界**：同场观察、势力网络、信息失真、衰减和“谁不知道”应成为可查询状态。
8. **势力状态缺少更明确的后勤/合法性/派系层**：仅有 attitude/tension/influence 不足以表达战功分配、代理人义务和公共危机问责。
9. **失败后果覆盖率不足**：每个高价值动作都应至少保留伤势、怀疑、债务、价格、关系、资源、区域危险或新线索中的一项。
10. **导演触发仍需多条件化**：不能只依赖日期阈值；应组合地点、热度、资源压力、已知事实、势力关系与观察者能力。
11. **世界级事件不能反向绑死早期路线**：高层内容应由长期状态触发并允许错过，不能要求玩家按小说章节顺序完成。
12. **验证边界需要保持清楚**：术语来源检查不等于剧情还原；确定性种子长跑不等于平衡、覆盖或小说真实性证明。

## 五、推荐下一阶段实现顺序

### P0：把信息、资源和失败后果接成一个可玩闭环

1. 定义统一 `Fact/Intel` 契约，接入 `knowledge`、NPC memory、rumor、交易和导演候选；实现验证、出售、伪造、过期四类动作。
2. 把元石、时间、材料、治疗容量和情报做成多用途资源；补资源短缺、价格反馈、抵押/债务和区域再生。
3. 将身份伪装拆成公开形象、真实身份、怀疑度、证据链、暴露后果；让 NPC 只读取自己的知识。
4. 将所有高价值 action 的失败结果统一写入 `History`、`consequences`、memory 和 faction 状态。

P0 验收：同一 seed 下至少能通过“囤货套利”“秘密探索”“公开扬名”三条路线完成早期生存；三条路线的 NPC 记忆、价格、怀疑度和势力态度不同。

### P1：传承、拍卖、演武与危机的组合验证

1. 把花酒遗藏/白骨/三王抽象为同一 `inheritance` 契约：线索、资格、轮次、顺序、竞争者、贪婪惩罚和失败保留。
2. 扩展市场/拍卖：观察、竞价、抬价、情报出售、抵押、借贷、付款来源和交易追踪。
3. 强化演武：观察对手、下注、连胜、伤势恢复、故意示弱、出售战斗情报和公开名声。
4. 把狼潮/前线做成持续危机：补给、巡逻、救援、战功、伤亡、战后问责和三方关系重排。
5. 为 NPC 增加“目标推进—传闻传播—行动适应”测试，覆盖玩家不在场时的结算。

P1 验收：同一危机可由战斗、交易、挑拨、救援、等待或绕路改变，且其他势力在玩家不行动时继续推进。

### P2：中期身份、基地和跨域博弈

1. 实现北原型跨域合法性、地域压制、常山阴式身份和暴露后的多势力反应。
2. 把福地/基地经营接入生产、贸易制裁、居民记忆、入侵和迁徙。
3. 实现代理人合同、联盟/背叛、奖励归属、来客资格和后勤义务。
4. 将梦境先做成低频 `dream` affordance，复用知识、效果、压力和事件账本，不单独造一套剧情引擎。

### P3：世界级导演与终局压力

1. 将五域战争、两天重叠、疯魔窟和天道/人道事件统一为多方状态阈值。
2. 让天庭、长生天、超级势力和个人势力在玩家不参战时推进；玩家通过情报、资源、代理人和窗口改变局部权重。
3. 实现稀有高代价重启/世界回响，确保它保留记忆但不抹除既有后果。

## 六、最小可执行数据契约

每个爽点至少要能回答三件事：它改变了哪些状态？哪些系统会观察到？哪些 NPC/势力会记住？建议所有高价值交互最终产生一条事实和一个领域事件：

```js
{
  type: 'information.revealed',
  actorId: 'player',
  subjectId: 'inheritance:flower-wine',
  fact: 'entrance_requires_wine_trace',
  source: 'observed',
  confidence: 0.72,
  knownBy: ['player'],
  valueByFaction: { merchants: 5, clan: 8, rivals: 7 },
  expiresAt: 42,
  consequences: {
    memory: 'player_found_hidden_rule',
    faction: { clan: { tension: 2 }, rivals: { suspicion: 3 } },
    directorPressure: 1
  }
}
```

这份契约不是要求立刻新增所有字段，而是作为后续实现的审计门槛：没有可查询事实、可结算事件和长期观察者，就只能算文案或一次性场景，不能算 simulation-first 爽点系统。

## 七、审计摘要

当前 gu-rpg 已经拥有持续世界、组件实体、区域 affordance、事件账本、NPC 记忆/传闻、势力容器和多个内容状态；下一阶段的瓶颈不是“再加更多章节”，而是把信息差、伪装、资源多用途、规则传承、失败后果和势力反应接成同一条可重复循环。优先做 P0/P1，验证玩家能以买、骗、等、威胁、合作、绕路、公开或隐藏改变同一局势；梦境、五域战争和终局重排保持为读取前置状态的稀有导演层。
