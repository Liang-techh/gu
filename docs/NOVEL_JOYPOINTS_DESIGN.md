# 《蛊真人》爽点与 simulation-first RPG 设计报告

> 研究范围：只使用 `reference/novel` 现有原文，并对照 `src/content.js`、`src/simulation.js`、`src/repeatable-systems.js`、`src/gu-director-rules.js` 与 `docs/SIMULATION_ARCHITECTURE.md`。
>
> 目标：把原文中最有驱动力的“爽点”拆成可重复行动、导演事件、NPC 记忆和势力状态，让玩家自由行动时仍能产生类似的紧张、反转和跃迁感；不把小说章节改写成线性任务树。

## 一、结论摘要

《蛊真人》的爽感不是单一的“数值变强”，而是四个状态同时发生变化：

1. 玩家掌握了别人不知道的信息，或者成功隐藏了别人想知道的信息。
2. 玩家把稀缺资源、地形、规则漏洞和敌人的欲望组合起来，以较小代价换取大收益。
3. 一次行动改变了人物关系、势力态度和区域压力，后续世界因此重新排列。
4. 看似已经失败的局面，在新的身份、资源、传承或世界规则揭示后反转。

因此，最值得优先实现的不是更多剧情文本，而是以下循环：

```text
获取线索/资源 → 选择是否公开 → 以行动试探规则 → 付出真实代价
      ↑                                      ↓
NPC记忆、势力反应、区域变化 ← 反转/追捕/新的机会窗口
```

当前代码已经具备较好的基础：`arena`、`inheritance`、`frontier`、`tower`、`central`、`worldWar`、`eternalWar` 等持续状态，与 `relationships`、`memory`、`factions`、`zones` 和导演规则相连。下一步应优先增强“信息不对称、伪装暴露、失败留下的长期事实、相同资源的多种用途”，而不是新增硬编码章节。

## 二、按爽点类型的原文证据

### 1. 绝境重启与先知优势

| 原文证据 | 爽点结构 | 可迁移的游戏含义 |
|---|---|---|
| 第1卷第1章《纵身亡魔心仍不悔》 | 方源被正道群雄围杀，确认必死后自爆，以春秋蝉重启；开头先给出“失败终局”，再把玩家送回青茅山。 | 失败不是简单读档，而是可以转成 `memory`、`facts` 或下一轮世界的预知；重启应有代价、残缺信息和新的变数。 |
| 第1卷第196章《再次重生》 | 三转巅峰被两名五转夹杀，战斗与逃跑都不可行，方源以自爆推动春秋蝉再次重来。 | 在“战力差距不可弥补”时提供高代价的逆转出口；出口应消耗蛊虫、身体、时间或未来确定性。 |
| 第2卷第124章《三王传承开启》 | 方源判断大事件具有惯性，先知优势使他在传承消息公开后集中购买驭犬蛊、纸鹤蛊、爆蛋蛊。 | 记忆不是直接奖励，而是提前布局、囤货、改变价格和改变竞争者数量的能力。 |
| 第5卷第2章《影无邪重生》 | 影无邪重生后没有立即复仇，而是判断天意、方源和影宗的大局，选择重建影宗。 | 重生者也应是 NPC 状态源；敌人会依据自己的记忆改变目标，不只是等待玩家触发。 |
| 第5卷第55章《和影宗交易（上）》 | “方源是天意棋子”的揭示，把玩家一直依赖的重生优势重新解释为被利用的风险。 | 对已知信息增加 `provenance`、可信度和误导可能；先知优势不能等同于绝对真相。 |

这里最适合做“记忆/状态系统”，其次才是导演事件。玩家可以选择相信记忆、公开记忆、利用记忆套利，或者故意制造一个会让别人误判的未来。重复系统可以提供“情报验证、囤货、试探”和“高代价重启”，但“某次重生揭示真相”应由导演在状态达到条件时触发。

### 2. 资源争夺、价格博弈与把贫穷变成筹码

| 原文证据 | 爽点结构 | 可迁移的游戏含义 |
|---|---|---|
| 第1卷第13—15章 | 方源只剩极少元石，仍买酒追踪花酒遗藏；面对月兰花交易和下毒陷阱，以信息和经验反制对方。 | 元石、食物、蛊材、时间和暴露度都应是可交换资源；“买不起”不应只等于不能行动。 |
| 第1卷第103—113章 | 方源先通过家产站稳脚跟，再在商队拍卖中有意多次“差一点成交”，只在关键物品上成功出价，借此被贾富看中。 | 拍卖不是随机买物品，而是价格、声誉、意图暴露、对手资本和谈判价值的组合系统。 |
| 第1卷第110—112章 | 酒虫价格低于市价；赤铁舍利蛊限时出售，方源必须在一天内筹资，甚至考虑抵押酒肆或竹楼。 | 物品应有时间窗口、抵押、借贷、经营现金流和错过后的市场变化。 |
| 第2卷第97章 | 大型拍卖会把三转以上蛊虫、秘方、传承信息、奴隶和兽王放在同一个市场；方源还会主动抬价消耗对手资本。 | 玩家可以买“资源”，也可以买“对手的未来行动空间”；竞价行为本身产生情报和敌意。 |
| 第2卷第106—109章 | 沮家因天灾变卖家产，灾难对沮家是损失，对其他势力却是稀缺货源；拍卖场真正的赢家是市场组织者。 | 区域灾害应改变供给、人口、势力和价格，而不是只生成一个战斗事件。 |
| 第4卷第98章、第119章 | 北原拍卖会把各大势力、仙蛊、身份密室和俘虏交易集中在一起；拍卖最大赢家反而因资源过多成为追杀目标。 | 资源越多越可能提高 `director.pressure`、追踪度和敌人动机；财富不能只给玩家正反馈。 |
| 第6卷第307章 | 两天洞天势力集体转投天庭，政治承诺、迁徙能力和保护网络成为资源。 | “资源”包括安全承诺、合法性和组织能力，不限于元石。 |

建议把当前 `auctionLot` 扩展为通用“市场动作”：竞拍、观察、出售情报、抬价、抵押、借贷、囤货、制造短缺都写入同一事件流。`state.central.auctionHeat` 可与 `factions.*.attitude/tension`、`memory` 和 `director.pressure` 联动。

### 3. 传承探索与“规则本身就是谜题”

| 原文证据 | 爽点结构 | 可迁移的游戏含义 |
|---|---|---|
| 第1卷第7章、第60章、第79章 | 花酒行者遗藏以酒香、石缝、机关和逐层蛊虫构成线索链；不是抵达地点就自动获得奖励。 | 传承应有线索、资格、误导、顺序、资源投入和被别人捷足先登的状态。 |
| 第1卷第163章《雷冠头狼》 | 天元宝莲需要元泉和大量元石才能补齐残叶，但摘取会废掉古月山寨的根基并引来追杀。 | 高价值资源必须同时是公共基础设施；取得它会改变区域经济与势力生存。 |
| 第2卷第23—25章《白骨传承》 | 正道传承要求克制贪欲，“三选其一”；取走不该取的东西会改变后续收获。 | 失败不只是受伤，也可以是失去隐藏奖励、改变传承路线或污染声誉。 |
| 第2卷第124章、第147章 | 三王传承公开后，正魔双方同时进入；犬王传承用大量犬群和关卡把战斗、奴道知识与资源争夺结合。 | `inheritance.round` 适合持续运行，但每轮应观察竞争者、区域危险和资源消耗。 |
| 第2卷第136章 | 白狐蛊仙传承牵动多个中洲门派，蛊仙不直接下场，把争夺转交给精英弟子。 | 高层势力可以通过代理人竞争，玩家的名声和关系会比单次战力更重要。 |
| 第3卷第91章、第102章 | 地丘传承可能只是低阶或陷阱；盗天传承是在炼蛊失败后意外发现，且线索仍不完整。 | 传承线索要有质量、可信度和兑现时间；探索失败可以产生新线索而不是归零。 |
| 第3卷第151—170章 | 真阳楼奖励强大，来客令稀缺；黑楼兰既需要方源的能力，又不愿分出奖励。方源在众人注意力集中时开启另一道传承。 | 资格令牌、外援、奖励归属和注意力窗口可以组成可重复的博弈。 |
| 第4卷第262章 | 十大派争夺星宿梦境，表面资源龙鱼反而不如梦境本身珍贵；方源以规则挑战和解梦能力翻盘。 | 把“占据权”“探索权”“三局两胜”和专门能力分开，形成资源所有权与使用权的博弈。 |
| 第5卷第152章、第6卷第241章 | 疯魔窟由无极魔尊布置，危险不是普通战斗，而是魔音、疯狂和世界终局；无极重生把遗产变成活的世界变量。 | 高层传承可以改变 `eternalWar.cosmicHeat`、梦境压力和势力目标，而不是一次性掉落。 |

传承最适合“重复系统 + 导演事件”的混合形式：导演负责开启传承窗口、改变竞争格局和揭示新层级；重复系统负责每轮探索的资源、检定、伤势、发现、竞争者行动和长期记录。

### 4. 身份伪装、信息不对称与反转

| 原文证据 | 爽点结构 | 可迁移的游戏含义 |
|---|---|---|
| 第1卷第7章 | 方源以酗酒、睡觉和丙等资质的外在形象隐藏真实目标；旁人把他的行为解释为颓废。 | NPC 观察到的是“公开形象”，不是完整真相；应区分 `publicProfile`、真实能力和怀疑度。 |
| 第1卷第138—143章 | 方源与白凝冰交锋，白方资质和真元优势让局面危险；方源通过距离、蛊虫和时机选择，不追求每次硬胜。 | 以弱胜强首先是选择“不打”的时机、范围和代价，而不是简单加攻击力。 |
| 第2卷第204章《白凝冰，你演够了吗？》 | 方源早已看穿白凝冰与铁家的布局，故意让她演下去，在自己炼蛊的关键时刻利用其底牌反转。 | `suspicion`、`knownBy`、`memory` 和“故意放过”应是常态状态；暴露不应自动发生。 |
| 第3卷第21章 | 方源以“常山阴”身份进入北原，利用跨域压制和外来人排斥，先以救援和狼王能力取得立足点。 | 身份不仅是名字，还决定地域合法性、能力压制、语言/文化门槛和势力信任。 |
| 第3卷第208章《身份暴露》 | 巨阳意志揭示“常山阴”并非真面目，黑楼兰和马鸿运重新评估方源，王庭局势立即转向。 | 身份暴露应改变多个 NPC 的记忆、关系、势力敌意和可用行动，而不是只弹一段文本。 |
| 第4卷第119章 | 拍卖后秦百胜被围杀，凤九歌通过卖家“沙黄”追查到方源；财富、交易记录和身份线索互相串联。 | 交易应留下可追踪的 `event provenance`；玩家可以匿名，但匿名不是无痕。 |
| 第5卷第55章 | 影宗揭示天意操盘和春秋蝉的另一层真相，改变方源对过去优势的解释。 | 真相可以分层揭示；同一事实可有公开解释、NPC解释和后续更深层解释。 |
| 第5卷第725章 | 白凝冰在八转战场中被龙灵认定为逃脱宿命的龙人，临死前获得新身份与新阵营入口。 | 身份揭示既可以是威胁，也可以是新能力、阵营和世界级目标的入口。 |

这一类爽点最适合由 `memory`、关系和势力状态承载，导演只负责“暴露窗口”或“新身份被某个高阶观察者识别”。建议新增通用概念（不要求本阶段立即改代码）：

- `identityMasks`: 玩家或 NPC 的伪装、可见标签、伪装强度、已知者集合。
- `suspicion`: 某个 NPC/势力对某一身份的怀疑度。
- `revealedFacts`: 已被谁确认的事实，和仅仅“听说”区分开。
- `informationValue`: 一条事实对不同势力的价格、威胁和可交换价值。

### 5. 以弱胜强、借势反杀与不对称战斗

| 原文证据 | 爽点结构 | 可迁移的游戏含义 |
|---|---|---|
| 第1卷第5章 | 开窍时方源只有丙等资质，方正是甲等；他在公开评价中落入下风，但这反而提供了隐藏空间。 | 资质、名声、真实战力和当前资源必须解耦。低评价可以是优势。 |
| 第1卷第60—79章 | 遗藏关卡依赖观察、真元管理和蛊虫组合，而非境界碾压。 | 战斗/探索检定应允许用 `insight`、情报和环境资源替代纯修为。 |
| 第1卷第147章 | 方源用七百元石换一只驭熊蛊，以援军不确定性迫使七名蛊师接受高价。 | 威胁、救援时延、稀缺资源和谈判关系可以替代战斗。 |
| 第2卷第204章 | 方源炼蛊时让白凝冰和铁家冲突，自己将战斗时间转化为完成仙蛊的时间。 | 让多个任务共享同一个“时间/注意力预算”；保护、炼制和逃生相互竞争。 |
| 第3卷第21章 | 南疆蛊师到北原战力被压一转，方源却用救援、诱导和当地蛊虫补足缺口。 | 跨域环境修正、当地装备和社会掩护能改变实力差距。 |
| 第4卷第262章 | 没有梦翼仙蛊的方源通过规则、荒兽和解梦杀招取得梦境占据权。 | 每个高价值内容至少提供一条非战斗解法：挑战规则、交易、代理人、情报或环境。 |
| 第5卷第539章 | 方源借长毛真意一举跃升炼道准无上，用境界资源解决琅琊福地迁徙难题。 | 稀缺知识可以改变系统能力上限，但应绑定资源、盟友信任和可用时机。 |
| 第6卷第307章 | 两天势力倒向天庭后，方源不追杀，南疆武家和西漠房家却用政治加入打出反击。 | “不行动”也可以是策略；不追杀保留元气，同时让盟友用不同方式改变局势。 |

### 6. 势力博弈、代理人和公共危机

| 原文证据 | 爽点结构 | 可迁移的游戏含义 |
|---|---|---|
| 第1卷第123章 | 狼潮逼迫三寨联盟，但联盟后的战功与利益分配更难；共同生存和互相提防同时存在。 | `faction.tension`、战功、补给、伤亡和关系应同时结算。 |
| 第1卷第127章 | 三族共同防狼、设立战功榜，以狼眼兑换蛊虫和元石。 | 公共危机适合转成重复任务；战功是个人行动连接势力资源的中间货币。 |
| 第1卷第154—155章 | 药堂权力、家族医疗资源和药脉政治在狼潮期间发生重排；方源用危机改变内部权力。 | 危机提高高层行动成本，也降低对次要案件的注意力，为玩家创造窗口。 |
| 第2卷第97章、第106章 | 商家城少主派系、演武场、拍卖场和家族破产互相影响。 | 城市不是商店集合，而是多个派系共享一个市场和声誉池。 |
| 第3卷第151—158章 | 黑楼兰需要外援闯楼，却不愿分享奖励；太白云生通过贿赂来客令寻求寿蛊，传承资格变成政治货币。 | `accessToken`、外援义务、奖励归属和公开名声应独立结算。 |
| 第4卷第1章、第98—119章 | 狐仙福地需要经营，同时被仙鹤门以贸易和胆识蛊施压；拍卖会把北原强者、资源与情报汇集，随后引发追查。 | 基地经营、贸易制裁、拍卖暴露和追捕可在同一世界账本中循环。 |
| 第5卷第280章、第417章、第671章 | 五域归一的大时代逼近；天庭擒获幽魂震动五域；长生天为反天庭与方源合作，敌人关系重新排列。 | 势力关系不是单轴善恶，而是多方在共同威胁下临时结盟、背叛、观望。 |
| 第6卷第367章 | 方源、巨阳与幽魂共同攻击天庭；天庭、长生天、个人势力与世界级灾变交织。 | 终局事件应允许多个势力同时推进，玩家只改变其中一部分，而不是单独触发胜利动画。 |

### 7. 世界级局势变化

| 原文证据 | 局势变化 | 系统化方向 |
|---|---|---|
| 第1卷第114—168章 | 狼潮从边缘威胁变成区域生存危机；三寨、资源、伤亡和政治权力全部重排。 | `zone.danger/activity/resources`、势力紧张、战功、NPC恐惧和人口伤亡共同变化。 |
| 第3卷第208—218章 | 身份暴露、王庭福地破灭、十年雪灾和真阳楼危机连续发生，幸存者甚至不知道完整真相。 | 世界事件应有不同观察者视角；事件账本是真相，NPC memory 是有偏差的投影。 |
| 第5卷第280章、第945章 | 五域界壁消失、五域归一，大时代真正开始；旧的地域规则和力量格局改变。 | `worldWar.heat` 不应只是数值，可改变旅行、交易、跨域压制、势力接触和新区域开放。 |
| 第6卷第241章、第335章 | 无极重生、天道梦境把世界结构本身变成可争夺对象。 | `eternalWar.cosmicHeat`、`dreamPressure`、天道/人道认知和终局阵营状态相互反馈。 |
| 第6卷第307章、第367章 | 两天势力倒向天庭，南疆和西漠又反向加入方源；三尊共同攻天庭。 | 世界级局势必须能在玩家不亲自参战时由 NPC/势力自行推进。 |

## 三、哪些内容放在哪一层

### A. 适合做可重复系统

这些内容的爽感来自“每次行动都可能改变账本”，不依赖固定章节：

- 演武/挑战：连胜、伤势、名声、对手资料、势力观察、下注和情报出售。
- 传承轮次：线索质量、资格、关卡、探索方式、竞争者、发现和失败后果。
- 拍卖/市场：竞价、观察、抬价、出售情报、抵押、借贷、囤货和制造短缺。
- 巡逻/战争：补给、战线、侦察、伏击、伤亡、战功和部族态度。
- 真阳楼/高危遗迹：层数、令牌、开放窗口、外援、奖励归属、世界压力。
- 梦境探索：进入成本、梦境深度、认知收益、精神反噬、现实关系变化。
- 炼蛊与资源经营：材料、成功率、时间、暴露度、交易和公共资源消耗。
- 情报行动：验证传闻、跟踪、伪造、传播、卖给不同势力，或让信息过期。

重复系统必须写入领域事件、`History`、NPC memory 和势力状态；只更新 UI 日志会失去《蛊真人》的长期爽感。

### B. 适合做导演事件

导演事件应当是“局势窗口”而不是“下一章”：

- 开窍大典、竹林酒香、学堂竞争、商队到来、狼潮逼近。
- 三王传承开放、狐仙传承消息、北原战报、王庭资格、真阳楼显化。
- 身份被某个高层观察者识破、交易链暴露、势力突然改变态度。
- 福地被制裁、影宗重新结网、五域战争升温、天庭公开重大消息。
- 神帝城调度、两天重叠、疯魔窟元境、梦境潮汐、星宿计划。

导演每次只提供几个有代价的选择，并让玩家也可以忽略或延迟。选择的后果应由通用动作和持续系统结算，而不是在导演规则中直接写死“剧情结果”。

### C. 适合做 NPC 记忆/势力状态

适合长期留下的事实包括：

- 谁帮助过谁、谁欺骗过谁、谁在危机中逃走或救援。
- 谁知道玩家的真实身份、谁只是听到传闻、谁明确怀疑但没有证据。
- 玩家是否遵守传承规则、是否贪取超额奖励、是否在公共危机中囤货。
- 玩家在演武场的连胜/败绩、在战争中的战功/伤亡、是否保护过补给线。
- 哪个势力获得了资源、失去了资源、被玩家公开羞辱或被玩家秘密帮助。
- 某个地点曾经发生过什么：资源枯竭、传承被开启、拍卖热度、战火、灾害、梦境污染。

建议保持当前两层结构：

- `entities.*.memory.facts` 保存可查询的事实；`episodes` 保存带时间和情绪的经历。
- `relationships[key]` 保存 `trust / fear / debt / affinity / lastSeen`。
- `factions[id]` 保存 `influence / tension / attitude / relations`；战线与危机再使用 `frontier / worldWar / eternalWar`。

## 四、自由行动下的状态变量、触发条件、失败后果和组合交互

下面的设计以当前字段为主，新增字段只作为未来的最小扩展建议。

| 系统 | 主要状态变量 | 触发条件 | 失败/忽略后果 | 可组合交互 |
|---|---|---|---|---|
| 隐藏与身份 | `player.memory.facts`、NPC `memory`、`relationships.*.fear/trust`；建议增加 `suspicion` | 玩家使用伪装、跨域旅行、公开高阶蛊术、交易高价值物品，或被高阶观察者接触 | 怀疑增长；交易链可追溯；NPC 可能停止援助、报告势力或提前设伏 | 伪装 + 拍卖匿名 + 情报出售；伪装 + 演武公开名声；身份暴露 + 势力制裁/招揽 |
| 资源经营 | `inventory`、`zones.resources/activity/danger/visits`、`cultivation.essence`、`needs` | 采集、炼蛊、拍卖、抵押、经营、公共危机 | 缺元石/材料；饥饿、伤势、炼蛊失败；区域资源枯竭或价格上涨 | 采集 + 市场囤货；炼蛊 + 传承资格；区域枯竭 + NPC 迁移 + 势力紧张 |
| 演武与挑战 | `arena.matches/wins/losses/streak/reputation`、身体伤势、关系记忆 | `arena.active` 且玩家在商家城；可扩展下注、观察、情报 | 连胜中断、伤势、名声下降；对手获得玩家能力资料 | 连胜 + 商家影响；失败 + 借贷/治疗；情报出售 + 对手难度变化 |
| 传承探索 | `inheritance.round/attempts/difficulty/discoveries/completed`、`facts`、`director.pressure` | 传承窗口开启、位置正确、资格/线索满足 | 受伤、精力下降、错过奖励、改变传承路线；其他队伍先推进 | 侦查 + 降低首次风险；贿赂/交易 + 改变竞争者；贪取超额奖励 + 后续隐藏奖励消失 |
| 拍卖与信息市场 | `central.auctionHeat/lotsSold/sectPressure`、`facts.auctionIntel`、元石 | 拍卖开放；玩家可竞拍、观察、抬价或卖情报 | 资源耗尽、意图暴露、热度引来追踪；卖假情报会损失可信度 | 拍卖 + 身份伪装；卖情报 + 势力关系；抬价 + 对手破产/敌意 |
| 北原战争 | `frontier.supply/campaignPressure/battles/casualties`、黑家/部族势力状态 | 前线开放；军需足够；玩家选择巡逻、侦察、调停或动员 | 补给消耗、伏击、人员伤亡、部族紧张；战线可能后退 | 巡逻 + 名声；调停 + 黑家影响下降；出售情报 + 东方盟军敌意上升 |
| 真阳楼/高危塔楼 | `tower.formed/floors/attempts/discoveries`，`frontier.campaignPressure` | 塔楼显化、来客资格、战争/天气窗口 | 受伤、闯层失败、楼层状态变化；外部战局会改变难度 | 后勤援助 + 延迟探索；外援 + 奖励分配冲突；身份暴露 + 资格被取消 |
| 梦境与认知 | `eternalWar.dreamPressure/dives/successes/failures`、`facts.dreamDepth` | 梦境潮汐开启；玩家有进入方式或盟友 | 精神/身体损伤、压力累积、现实关系改变；高压时成功率下降 | 梦境探索 + 身份真相；梦境资源 + 区域危险；梦境失败 + NPC 误解/势力介入 |
| 世界级战争 | `worldWar.heat`、`eternalWar.cosmicHeat`、各势力 `tension/attitude/influence` | 多个区域热度、资源压力或高层事件达到阈值 | 旅行规则改变、势力结盟、区域灾害、玩家失去安全基地 | 任何地方行动都可能改变世界热度；势力合作/背叛改变导演候选；梦境/遗迹成为战争目标 |

### 关键触发原则

1. 触发应由多个条件组成：地点 + 时间/热度 + 资源压力 + 已知事实 + 势力关系，而不是单个 `day >= N`。
2. 失败必须保留至少一个长期结果：伤势、怀疑、价格变化、NPC 记忆、势力紧张、区域资源消耗或新线索。
3. 同一资源至少有两种用途。例如元石既能修炼、竞拍、补充传承，也能买情报、贿赂和救援；时间既能等待恢复，也能让战争、价格和 NPC 目标推进。
4. 不行动也是行动。玩家忽略狼潮、拍卖、传承或盟友求援时，其他势力应继续结算，不要暂停世界。
5. 公开成功与秘密成功要分开。玩家可以获得奖励但暴露身份，也可以只拿到部分奖励并保持匿名。

## 五、优先级排序

### P0：先把早期爽点变成可反复玩的状态循环

1. 开窍大典/学堂竞争：资质、公开形象、方正关系、家老关注和竞争者记忆。
2. 元石—蛊虫—炼蛊—采集的基础经济：加入价格、消耗、风险和区域资源恢复。
3. 竹林酒香—花酒遗藏：线索质量、探索顺序、传承奖励与家族追查。
4. 演武和战斗：保留当前 `arena`，增加观察、下注、出售情报和对手记忆。

P0 的验收标准不是“能看到更多文本”，而是同一个开局在不同资质、不同关系和不同资源选择下，能形成至少三种合理生存路线。

### P1：强化已有系统的反转与势力联动

1. 商队/拍卖/贾富：竞价意图、资源囤积、交易追踪、借贷和势力反应。
2. 狼潮与三寨联盟：补给、战功、伤亡、救援时延、三族利益分配。
3. 白骨山和三王传承：周期性开放、竞争者推进、传承规则、贪婪惩罚。
4. NPC 记忆传播：同场观察、传闻扩散、势力网络传播和信息失真。

P1 完成后，玩家应能通过“买、骗、等、威胁、合作、绕路、公开或隐藏”改变同一局势，而不必按小说顺序触发。

### P2：中期身份与高层资源

1. 北原伪装与跨域压制：常山阴型身份、当地合法性、怀疑度和身份暴露。
2. 王庭/真阳楼：来客令、外援义务、奖励归属、战争后勤和闯层压力。
3. 狐仙福地经营与宗门压力：基地资源、贸易制裁、谈判、攻防和影宗线。
4. 梦境争夺：所有权、探索权、解梦能力、梦境压力和现实后果。

P2 的重点是“玩家赢了但被看见”“玩家输了但拿到关键线索”“玩家没有参战却改变了战局”等非二元结果。

### P3：世界级局势与终局压力

1. 影宗重建、五域战争、天庭/长生天/超级势力关系。
2. 神帝城、人道战线、两天重叠和疯魔窟。
3. 天道梦境、尊者重生、三尊攻天庭等高层导演事件。

P3 不应成为一条固定终局线。应允许玩家留在早期区域经营，也允许玩家通过情报、贸易、代理人或间接支持影响世界级热度；世界仍然会在无人干预时推进。

## 六、避免硬编码线性主线的实施约束

- 内容包只保存地点、人物、势力、资源、来源章节和候选事件；不要把“第 X 章之后才能做 Y”作为唯一门槛。
- `source` 只说明原文依据，不等于必须复现原文结局。玩家可以在同样的状态条件下做出不同选择。
- 导演规则只生成候选事件和选择，不直接修改玩家数值；所有后果进入 `dispatch`、Action、Event、History、memory 和 faction 系统。
- 对每个新增爽点写清楚三个问题：它改变了哪些状态？哪些系统会观察到？哪些 NPC/势力会记住？答不出来的内容应留在文案层，不应进入核心模拟。
- 章节证据应分为“原文事实”“系统抽象”“设计推断”三层。不要把小说中一次性的巧合直接伪装成稳定概率，也不要把战力描写直接转成可证明的数值比例。
- 运行固定种子长跑只能验证世界状态没有崩坏，不能证明剧情覆盖、平衡或原文还原；新系统仍需针对资源耗尽、身份暴露、失败后果、NPC 自主推进和存档恢复做定向测试。

## 七、推荐的最小数据契约

如果后续要进一步扩展，建议每个高价值爽点只增加一份可查询的事实和一份可结算的事件：

```js
{
  type: 'information.revealed',
  actorId: 'player',
  subjectId: 'fangyuan',
  fact: 'masked_identity',
  confidence: 0.7,
  knownBy: ['heiloulan'],
  value: { heavenlyCourt: 9, black: 6, merchants: 4 },
  consequences: {
    relationship: { trust: -5, fear: 8 },
    faction: { tension: 4 },
    directorPressure: 2
  }
}
```

这类事件既可以被日志显示，也可以被 NPC AI、Rumor、导演、势力关系和存档恢复读取。最终的“爽”来自玩家看到世界因为自己的选择而重新解释自己，而不是看到一段预先决定的章节文本。
